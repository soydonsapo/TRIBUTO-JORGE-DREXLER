# Tributo a Jorge Drexler

Proyecto inicial con React y JavaScript, creado con la plantilla oficial de Vite.

## Desarrollo

Requiere Node.js 24 LTS y npm. Si acabas de instalar Node.js, abre una terminal nueva.

```powershell
npm.cmd install
npm.cmd run dev
```

Abre la dirección local que indique Vite (normalmente http://localhost:5173).
Edita `src/App.jsx` para comenzar y `src/App.css` para cambiar los estilos.

## Comprobaciones

```powershell
npm.cmd run lint
npm.cmd run build
npm.cmd run preview
```

La compilación se genera en `dist/`. El comando preview permite revisarla localmente.
La plantilla utiliza Oxlint para analizar el código.

En PowerShell se usa `npm.cmd` para evitar restricciones de ejecución de scripts de `npm.ps1`.
